# Brand icons (web)

Generated from `apps/mobile/assets/images/icon.png` (official merlot split bottle).

| File | Use |
| --- | --- |
| `favicon-16.png` / `favicon-32.png` | Browser tabs |
| `apple-touch-icon.png` | iOS home screen / Safari |
| `icon-192.png` / `icon-512.png` | PWA / Android |
| `og.png` | Link previews (iMessage, Slack, etc.) |
| `icon-1024.png` | Source-sized copy |
